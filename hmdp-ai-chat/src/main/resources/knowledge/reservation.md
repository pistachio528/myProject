# 餐厅预约说明

## 如何预约就餐
通过智能客服即可完成餐厅预约，无需跳转其他页面。告诉客服以下信息即可：
1. 商家名称（如：海底捞、外婆家）
2. 预约日期（如：明天、2026-05-20）
3. 预约时间（如：晚上6点半、18:30）
4. 就餐人数（1-20人）
5. 特殊要求（可选，如：靠窗位置、需要儿童椅、庆生布置等）

示例：帮我预约海底捞，明天晚上7点，4个人，需要靠窗位置

## 预约状态说明
预约提交后会有以下状态流转：
- **待确认**：预约已提交，等待商家确认
- **已确认**：商家已确认预约，请按时到店
- **已完成**：就餐已完成
- **已取消**：预约已取消

商家一般会在1小时内确认预约，高峰期可能稍慢，请耐心等待。

## 如何取消预约
可以通过智能客服取消预约，告诉客服"取消我的预约"即可。客服会先查询您的预约列表，确认后帮您取消。
注意：已确认的预约建议提前2小时取消，避免影响商家安排。

## 预约注意事项
1. 预约仅代表占位，不代表已支付，到店后按实际消费结算
2. 如需修改预约（时间、人数等），请先取消原预约再重新预约
3. 预约成功后请按时到店，迟到超过30分钟商家有权取消预约
4. 部分热门商家可能需要提前1-3天预约，建议提早安排
5. 预约信息仅供参考，最终以商家确认为准

## 查询我的预约
告诉客服"查询我的预约"或"我有哪些预约"，即可查看所有有效预约记录。
